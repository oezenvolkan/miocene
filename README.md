# Miocene diatoms at Southern Ocean drill sites (marimo app)

A marimo notebook exported to run in the browser (WebAssembly). Python runs in the visitor's browser; nothing to install.
Open the GitHub Pages link; the first load takes a little while as Python starts up.

Data: `public/neptune_miocene_diatoms_southern_ocean.csv` (Neptune database, Miocene diatoms, Southern Ocean DSDP/ODP holes).
